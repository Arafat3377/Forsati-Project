
# منصة فرصتي — Forsati

منصة ذكية للبحث عن فرص التدريب التعاوني في منطقة القصيم (مشروع جامعة القصيم - كلية التطبيقية).
Django + Python + SQLite/MySQL + ربط نموذج ذكاء اصطناعي.

## التشغيل
```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo        # بيانات تجريبية
python manage.py createsuperuser  # لوحة التحكم
python manage.py runserver
```
- الموقع: http://127.0.0.1:8000
- لوحة التحكم: /admin

## النشر على Render
ملف `render.yaml` يعرّف خدمة الويب وإعدادات البناء والتشغيل. يستخدم النشر PostgreSQL
لحفظ البيانات بشكل دائم؛ لا تعتمد على SQLite في الاستضافة لأن ملفاتها قد تُفقد عند إعادة النشر.
بيانات `db.sqlite3` المحلية لا تُنقل تلقائياً إلى PostgreSQL؛ احتفظ بالملف، وخطّط لنقل
البيانات بشكل منفصل إذا كانت مطلوبة على الموقع المنشور.

1. ارفع المشروع إلى مستودع GitHub.
2. أنشئ قاعدة بيانات PostgreSQL في Render، وانسخ **Internal Database URL**.
3. من Render اختر **New > Blueprint**، واربط مستودع GitHub بالمشروع. إذا لم يكتشف
   `render.yaml` تلقائياً، حدّد مساره في جذر المستودع.
4. عند طلب قيمة `DATABASE_URL`، الصق رابط قاعدة البيانات الذي نسخته، ثم أنشئ الموارد.
   يتولى Render تثبيت المتطلبات، وتجميع الملفات الثابتة، وتشغيل ترحيلات قاعدة البيانات.
5. بعد نجاح النشر، افتح رابط الخدمة وأنشئ حساب الإدارة من **Render Shell**:
   `python manage.py createsuperuser`
6. اختيارياً، أضف `AI_API_KEY` من **Environment** لتفعيل خدمات الذكاء الاصطناعي؛
   الموقع يعمل أيضاً بمحرك البحث المحلي عند عدم ضبط المفتاح.

## ربط نموذج الذكاء الاصطناعي
النظام يعمل بمحركين:
1. **محرك LLM** (عند توفر المفتاح): يفهم طلب الطالب بلغته الطبيعية ويستخرج
   (المجال، المدينة، الكلمات المفتاحية) ويرد بإجابة منسّقة.
2. **محرك محلي ذكي** (تلقائي بدون مفتاح): استخراج النية + مطابقة وتقييم TF-IDF مبسّط.

### التفعيل
في Windows PowerShell، ضع مفتاح OpenAI الحقيقي مكان `sk-...` ثم نفّذ:
```bash
setx AI_API_KEY "sk-..."
setx AI_BASE_URL "https://api.openai.com/v1"
setx AI_MODEL "gpt-4o-mini"
```
تُطبّق أوامر `setx` على نوافذ الطرفية الجديدة؛ افتح نافذة جديدة ثم شغّل التطبيق.

على Linux/macOS:
```bash
export AI_API_KEY="sk-..."
export AI_BASE_URL="https://api.openai.com/v1"   # أو أي API متوافق (Kimi, DeepSeek...)
export AI_MODEL="gpt-4o-mini"
```

## قاعدة البيانات
- SQLite افتراضياً (db.sqlite3).
- لتفعيل MySQL: عدّل DATABASES في forsati/settings.py (مثال جاهز داخله)
  وثبّت `pip install mysqlclient`.

## بنية قاعدة البيانات
- Organization: الجهات/الجامعات/الشركات (الشريحة 7)
- Opportunity: فرص التدريب (المجال، المدينة، المتطلبات)
- Application: طلبات الطلاب (قيد المراجعة/مقبول/مرفوض)
- User (جاهز في Django): حسابات الطلاب

## مسارات النظام
| المسار | الوظيفة |
|---|---|
| / | الرئيسية |
| /opportunities/ | تصفح وبحث الفرص |
| /ai-search/ | البحث الذكي بالذكاء الاصطناعي |
| /coach/ | مدرب المسارات المهنية (AI Training Career Coach) |
| /org/register/ | تسجيل شركة/مؤسسة/جامعة سعودية |
| /org/post/ | نشر فرصة تدريب (للجهات المسجلة) |
| /org/dashboard/ | لوحة تحكم الجهة (الفرص + المتقدمون + القبول/الرفض) |
| /my-applications/ | طلبات الطالب |
| /admin/ | إدارة الفرص والطلبات |

## الإضافات الجديدة (حسب ملاحظات المشرفة)
1. **بوابة الجهات**: أي شركة أو مؤسسة أو جامعة سعودية تسجّل حسابها ومن ثم تنشر
   فرصها التدريبية من `/org/post/`، وتتابع المتقدمين وتقبل/ترفض من `/org/dashboard/`.
2. **مدرب المسارات المهنية**: محادثة ذكية (/coach/) يرشد الطالب إلى:
   الفرص المناسبة لتخصصه، التهيئة للمقابلة، تحسين السيرة الذاتية،
   كتابة خطاب التقديم، والمهارات/المسار الوظيفي. يعمل بمحرك LLM عند توفر
   المفتاح، وبإرشاد محلي جاهز بدون إنترنت.
3. **الصفحة الرئيسية الجديدة**: صورة واجهة لسقف الرياض، شريط إحصائيات،
   أقسام الشركاء (جامعات/بنوك/مؤسسات حكومية) بشعارات SVG، معرض صور منطقة
   القصيم، ومجالات التدريب الأكثر طلباً.
